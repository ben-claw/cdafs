# CD Audio Filesystem (CDAFS)
cdafs - файловая система пользовательского пространства на базе FUSE, которая представляет аудио-CD в виде обычного каталога с WAV-файлами. Содержимое файлов генерируется при чтении и извлекается непосредственно с аудио-CD. Программа ориентирована на простоту использования и минимальное количество внешних зависимостей.
## Сборка и установка
В настоящий момент единственным способом установки является самостоятельная сборка из исходного кода. Вы можете получить исходный код программы двумя способами:
1) Скачать архив конкретного релиза:
  ```sh
  wget https://github.com/ben-claw/cdafs/releases/download/v0.1.0/cdafs-0.1.0.tar.gz
  tar -xf cdafs-0.1.0.tar.gz
  cd cdafs-0.1.0
  ```
2) Клонировать текущую версию из репозитория (требуются `git` и `GNU Autotools`):
  ```sh
  git clone https://github.com/ben-claw/cdafs
  cd cdafs
  autoreconf --install --force
  ```
Сборка выполняется командами
  ```sh
  CFLAGS="-O2" ./configure [--enable-debug] --prefix="$HOME/.local"
  make
  ```
Необязательный параметр `--enable-debug` включает дополнительный отладочный вывод и не рекомендуется для обычных пользователей.
Параметр `--prefix` определяет префикс пути установки. Значение по умолчанию - `/usr/local`.

При успешном завершении сборки будет создан исполняемый файл `./src/mount.cdafs`. Установка файла в каталог `$(PREFIX)/sbin` выполняется следующей командой (может потребовать прав root)
  ```sh
  make install
  ```
## Использование
Программа очень проста в использовании. Просто создайте точку монтирования и выполните:
  ```sh
  mount.cdafs /dev/cdrom /mount/point/
  ```
После монтирования каталог `/mount/point/` будет содержать (псевдо)файлы с именами `trackNNN.wav`, где NNN - номер трека с ведущими нулями. Эти файлы можно скопировать на локальный диск или воспроизвести в вашем любимом плеере как обычные WAV-файлы.

Для монтирования не требуются права `root`, но требуются права на чтение `/dev/cdrom` и монтирование в `/mount/point/`.
## Зависимости для запуска
- ядро Linux с поддержкой FUSE (протестировано на `6.18.35`);
- `libfuse` версии `2.6` или новее (протестировано на `2.9.9`);
- стандартная библиотека C (протестировано на `glibc 2.43`);
- доступ к CD-приводу.
## Зависимости для сборки из исходного кода
- GNU Autoconf (протестировано на `2.72`);
- GNU Automake (протестировано на `1.18.1`);
- заголовочные файлы `libfuse`, соответствующие установленной версии библиотеки;
- `pkg-config` (протестировано на `2.5.1`);
- компилятор C (протестировано на `gcc 15.3.0`);
- `make` (протестировано на `GNU Make 4.4.1`).
## Планы на будущее
- поддержка FUSE 3 с выбором между FUSE 2 и FUSE 3 при конфигурации;
- переход на `libcdio`/`libcdio-paranoia` для обеспечения переносимости на другие Unix-подобные операционные системы;
- добавление поддержки разграничения доступа для разных пользователей;
- исправление ошибок и повышение стабильности.
